# 스마트 분실물 키오스크 — 실행 가이드

## 구조
```
index.html   화면 구조 (홈 / 등록 / 찾기 / 순차질문 / 후보선택 / 최종본인확인 / 성공·실패)
style.css    디자인 (이름표 태그 모티프)
script.js    클라이언트 로직 (서버 API 호출)
server.js    로컬 서버 — 정적 파일 서빙 + data.json 실제 파일 입출력
data.json    실데이터 저장소 (카테고리/장소/색상 등 메타 + 등록된 물품 목록)
```

## 태블릿에서 실행 (안드로이드 스튜디오 불필요)
1. 태블릿에 **Node.js**가 설치되어 있어야 합니다 (없으면 nodejs.org에서 LTS 버전 설치, 또는 Termux 등에서 `pkg install nodejs`).
2. 이 폴더 전체를 태블릿에 복사합니다.
3. 터미널에서 실행:
   ```
   node server.js
   ```
   → `http://0.0.0.0:8080` 로 뜹니다. 콘솔에 `PORT` 환경변수로 포트를 바꿀 수 있습니다 (`PORT=9000 node server.js`).
4. 태블릿의 실제 IP (설정 > Wi-Fi > IP 주소, 예: `192.168.0.23`)를 확인합니다.
5. **HAKiosk 앱**에 시작 URL로 `http://192.168.0.23:8080` (태블릿이 자기 자신에게 접속하는 경우) 을 등록하고, 키오스크 모드로 실행합니다. HAKiosk가 그 주소 밖으로 못 나가게 잠가주므로 별도 앱 빌드가 필요 없습니다.
6. 재부팅 시 자동 실행이 필요하면, OS의 시작프로그램/작업 스케줄러에 `node server.js`를 등록하세요 (Windows 태블릿이면 시작 프로그램 폴더에 배치 파일 추가, 리눅스 기반이면 systemd 서비스 또는 crontab `@reboot`).

## 데이터 저장 방식
- 이제 `localStorage`가 아니라 **`data.json` 파일 자체**가 진짜 저장소입니다.
- 등록/수령/카테고리 추가 등은 모두 `fetch()`로 서버에 요청 → 서버가 `data.json`을 다시 씁니다.
- 브라우저를 껐다 켜거나 태블릿을 재부팅해도 `node server.js`만 다시 켜면 데이터가 그대로 남아 있습니다.
- 홈 화면의 "전체 데이터 초기화"는 서버가 **최초 기동된 시점의 데이터**로 되돌립니다 (발표/시연 전 정리용). 서버를 재시작하면 그 시점의 `data.json`이 새 기준점이 되니, 완전히 깨끗한 상태로 되돌리고 싶으면 서버를 껐다가 `data.json`을 초기 시드로 교체 후 재시작하세요.

## 본인확인(찾기) 흐름
1. **후보 좁히기**: 분류 → 층 → 위치 → 색상 → 재질 → 특징 순으로 질문. 모든 질문에 "모르겠어요"와 "직접 입력"이 항상 있어 답을 몰라도 막히지 않습니다. 후보가 1개로 좁혀지면 바로 다음 단계로 넘어갑니다.
2. **후보가 여러 개 남으면**: 이름은 보여주지 않고 코드/특징 요약만 보여주는 선택 화면이 뜹니다.
3. **최종 본인확인(4문항)**: 브랜드/모델/사이즈/재질/색상/특징 등 실제 등록 데이터 기반으로 문항이 자동 생성되고, 오답 보기는 다른 실제 등록 물품 데이터에서 가져옵니다. 물품명은 절대 문제로 나오지 않습니다. 4문항 중 3문항 이상 맞으면 통과, "모르겠습니다"는 중립 처리됩니다.
4. 통과 시 물품명 + 보관 코드를 공개하고, 수령자 이름만 받은 뒤 행정실 방문을 안내합니다.

## 커스터마이징 포인트
- `data.json`의 `meta` 값(층/카테고리/색상 등)을 직접 수정해 학교 상황에 맞게 초기값을 바꿀 수 있습니다.
- 등록/찾기 화면의 질문 순서·항목은 `script.js`의 `NARROW_FIELDS`, `CHALLENGE_FIELD_PRIORITY` 배열에서 조정합니다.
- 디자인 토큰(색상/폰트)은 `style.css` 상단 `:root` 변수에서 한 번에 바꿀 수 있습니다.
