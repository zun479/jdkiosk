# 스마트 분실물 키오스크 — 로컬 버전

학교 분실물 보관·수령을 위한 터치스크린 키오스크 웹앱. 10.5인치 / 1920×1200(16:10) 태블릿 기준으로 만들어졌습니다.

**이 저장소(`jdkiosk`)는 "로컬 버전"입니다.** 인터넷/클라우드와 일절 통신하지 않습니다. 데이터는 전부 이 기기(태블릿)의 브라우저 저장소(IndexedDB)에만 저장됩니다.

> 클라우드 자동 백업이 딸린 버전이 필요하면 별도 저장소 **`jdkiosk-Live`**를 쓰세요 (Vercel/Cloudflare Pages 등에 그대로 올리는 온라인 배포용).

---

## 1. 이 저장소에 포함된 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 화면 마크업 |
| `style.css` | 디자인 |
| `script.js` | 클라이언트 로직 전체 (등록/찾기/퀴즈/관리자/저장) — **외부로 나가는 `fetch()` 호출이 코드 전체에 하나도 없습니다** |
| `README.md` | 이 문서 |

세 파일(`index.html`, `style.css`, `script.js`)만 있으면 됩니다. `server.js`나 `data.json` 같은 건 필요 없습니다 — `script.js` 안에 초기 데이터(`seedData()`)와 저장 로직(IndexedDB)이 전부 내장돼 있습니다.

## 2. 태블릿 배포 방법 (Simple HTTP Server PLUS 기준)

1. `index.html`, `style.css`, `script.js` 세 파일을 태블릿의 한 폴더에 복사
2. Simple HTTP Server PLUS에서 그 폴더를 Root Folder로 지정하고 포트 지정(예: `3000`) 후 Start
   - **Allow file modification**, **Enable WebDAV**, **CGI/Commandline scripts**는 전부 꺼두세요 (이 앱은 서버가 파일을 쓰거나 명령을 실행할 일이 없습니다)
   - **Autostart on boot**는 켜기, **Auto shutdown by inactivity**는 반드시 끄기
   - **Restrict network interfaces**를 켜서 localhost(127.0.0.1)로만 제한하는 것을 권장 (외부에서 접속 못 하게)
   - **Use TLS encryption**은 끄기 (로컬 정적 파일이라 필요 없음)
3. FreeKiosk에서 `http://localhost:3000`(설정하신 포트)을 열고 화면 잠금
4. 화면 꺼짐은 안드로이드 기본 자동 절전 + FreeKiosk 화면 보호기 조합으로 충분 — 전원을 완전히 끄는 방식은 예약 재부팅을 지원하지 않으니 쓰지 마세요

> ⚠️ **포트 번호를 나중에 바꾸면** (예: 8080 → 3000), 브라우저는 이걸 완전히 다른 사이트로 취급합니다. IndexedDB에 저장된 기존 데이터(등록된 물건, PIN, 커스텀 태그 등)가 새 포트에서는 안 보이게 됩니다 — 삭제된 게 아니라 접근이 안 되는 것뿐입니다. 그래서 **"데이터 내보내기"로 미리 백업해두고 "데이터 가져오기"로 새 포트에서 복원**하는 걸 권장합니다.

## 3. 데이터는 어디에 저장되나

- **유일한 저장소는 이 기기의 IndexedDB(브라우저 내장 저장소)입니다.** 등록·수령·삭제 전부 즉시 여기 저장되고, 태블릿을 껐다 켜도 남아있습니다.
- **인터넷 연결이 아예 없어도, 처음부터 끝까지 100% 정상 동작합니다.** 코드 어디에도 외부로 나가는 네트워크 요청이 없습니다.
- 브라우저/앱의 캐시·데이터를 완전히 초기화하면 데이터가 함께 사라집니다. 그래서 관리자 화면의 백업 기능을 꼭 활용하세요:
  - **데이터 내보내기**: 전체 데이터를 JSON 파일로 다운로드
  - **데이터 가져오기**: 그 JSON 파일로 복원
  - **화면에 직접 표시**: 다운로드 자체가 안 되는 웹뷰를 위한 대체 — 전체 데이터를 화면에 텍스트로 띄워 길게 눌러 복사 가능
  - **자동 백업 파일 지정** (지원 브라우저에서만, File System Access API): 파일 하나를 한 번 지정해두면, 데이터가 바뀔 때마다 같은 기기 안의 그 파일에 자동으로 덮어써서 저장 — 이것도 완전히 로컬 동작이라 인터넷이 필요 없습니다

## 4. 습득물 등록 (4단계)

| 단계 | 내용 |
|---|---|
| 1 | 물품명(필수), 습득 날짜 — `[오늘]` / `[날짜 선택]`, 날짜 선택 시에만 캘린더 노출 |
| 2 | 습득 층(필수) → 층을 고르면 위치 목록이 자동 스크롤로 나타남 |
| 3 | 분류(10종) → 세부 종류 → (일부는) 더 자세히까지 스무고개식 세분화 → 색상(실제 색상 배경 그리드) |
| 4 | **사진(필수, 없으면 등록 자체가 막힘)** + **직접 촬영 버튼**(전면 카메라, "다시 촬영" 가능), 모델명/제작사(선택), 접이식 내용물·숨겨진 특징(본인확인 퀴즈 전용), 재질/특징/사이즈, 메모 |

분류·세부종류·상세종류·색상·재질·특징·내용물·숨겨진 특징은 전부 **자가성장형 태그** — 목록에 없으면 "+ 직접 입력"으로 추가됩니다. `◀`는 홈으로 바로 안 나가고 `[이전]`과 동일하게 한 단계씩 되돌아갑니다.

## 5. 분실물 찾기

1. **후보 좁히기**: 층 → 위치 → 분류 → 세부종류 → 상세종류 → 색상 → 재질 → 특징. 모든 질문에 "모르겠어요"·"직접 입력" 있음.
2. **본인확인 퀴즈(5~8문항, 완전 결정론적 — 유사도 판단 없음)**
   - 태그형(내용물/숨겨진특징/특징/색상): `"[키워드]가 있었나요?"` → 실제 등록 배열에 있는지 true/false만 비교
   - 단일값(브랜드·모델/사이즈/재질/분류/세부종류/상세종류/층/위치): 문자열 완전 일치 객관식
   - 정답 기준 75% 이상 또는 오답 1개 이하
3. **후보가 여러 개면** 퀴즈 전에 사진으로 먼저 골라볼 수 있음 (위치/날짜를 몰라도 사진은 알아볼 수 있으므로). 틀리면 최대 2번 재시도.
4. **최종 사진 확인** → **학번(5자리 숫자)+실명(한글/영문 2자 이상, 특수문자·숫자·공백 불가) 입력해야만 수령 완료 버튼 활성화**

⚠️ 위치/날짜를 몰라도 사진만으로 수령까지 가능한 구조라, 관리자 화면에는 그 경로로 수령된 항목의 이름 옆에 **빨간 동그라미**가 표시됩니다 (하단에 10px 크기로 설명 문구도 같이 뜸).

## 6. 관리자 화면

- 홈 화면 "N개 보관중입니다"의 **숫자를 더블클릭** → PIN 입력(기본 `2010`, `script.js`의 `seedData()` 안 `settings.managerPin`에서 변경)
- 전체 항목 목록 + 사진 데이터 예상 용량 표시
- 항목 탭하면 사진 열람 + 전체 필드 수정 + 삭제 + 수령 상태 변경
- **데이터 내보내기/가져오기**, **화면에 직접 표시**, **자동 백업 파일 지정** (3절 참고)
- "전체 데이터 초기화": 최초 시드 데이터로 되돌림 (되돌릴 수 없음)
- **확인 팝업은 브라우저 기본 `confirm()`을 안 씁니다.** 일부 키오스크 잠금 브라우저는 OS 레벨 팝업(`confirm`/`alert`/`prompt`)을 차단해서 눌러도 반응이 없는 것처럼 보일 수 있어, 자체 제작한 확인 모달(`showConfirm()`)을 씁니다. "전체 데이터 초기화", 항목 삭제 전부 이 방식입니다.

## 7. 홈 화면

- 다크 테마 고정, 다른 화면으로 넘어가면 부드럽게(0.6s) 밝은 테마로 전환, 홈으로 돌아오면 다시 다크로
- 좌하단에 작은 **[키오스크 상태]** 한 줄짜리 바 (화면 진짜 모서리, 6px): 자동 백업 파일 지정 여부 / 마지막 로컬 백업 시각 / 배터리(지원 브라우저에서만, 폴링 아닌 이벤트 기반이라 배터리 소모 거의 없음)

## 8. 커스터마이징 포인트

모두 `script.js` 안에 있습니다:
- **분류/세부종류/상세종류, 층/위치, 색상, 재질, 특징, 내용물, 숨겨진 특징 태그**: `seedData()` 함수
- **관리자 PIN**: `seedData()`의 `settings.managerPin`
- **퀴즈 문항 수/필드 우선순위**: `TAG_FIELDS`, `CHOICE_FIELDS`, `MIN_QUESTIONS`, `MAX_QUESTIONS`
- **사진 압축 강도**: `compressImageFile(file, maxDim, quality)` 기본값(900px / 0.7)
- **디자인 토큰**: `style.css` 상단 `:root` 변수

`seedData()`를 고친 뒤에는, 이미 데이터가 쌓인 태블릿이라면 관리자 화면의 "전체 데이터 초기화"를 눌러야 새 시드값이 반영됩니다 (기존 데이터가 있으면 시드는 최초 1회만 적용되기 때문입니다).
